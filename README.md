# Diabetes Prediction Using Logistic Regression

## Project Overview
This project uses Machine Learning to predict whether a person is likely to have diabetes using the Logistic Regression algorithm.

The model analyzes medical information such as glucose level, blood pressure, BMI, age, insulin level, and other health-related features to predict diabetes risk.

## Objectives
- To predict diabetes using Machine Learning.
- To understand the Logistic Regression algorithm.
- To analyze medical datasets.
- To evaluate the accuracy of the prediction model.

## Technologies Used
- Python
- Google Colab
- Machine Learning
- Logistic Regression
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The project uses a diabetes dataset containing medical attributes such as:
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## Algorithm Used
**Logistic Regression**

Logistic Regression is a supervised Machine Learning algorithm used for binary classification. It predicts whether a person belongs to one of two classes: diabetic (1) or non-diabetic (0).

## Project Workflow
1. Import the required libraries.
2. Load the diabetes dataset.
3. Perform data preprocessing.
4. Split the dataset into training and testing data.
5. Train the Logistic Regression model.
6. Evaluate model performance.
7. Predict diabetes outcomes.

## How to Run
1. Download the project notebook.
2. Open Google Colab.
3. Upload the `.ipynb` file.
4. Run all the cells.
5. View the prediction results.

## Expected Output
The model predicts:
- 0 – Non-Diabetic
- 1 – Diabetic
